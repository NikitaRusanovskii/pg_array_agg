### Ограничения

+ Поддерживаются только массивы с числом измерений: 0, 1, 2. Массивы с ndim > 2 вызывают ошибку.

+ Типы элементов массивов ограничены списком, приведённым в general. Пользовательские типы не поддерживаются.

+ Предикаты имеют ограниченный синтаксис: только простые условия вида x op const или x op const = const. Сложные логические выражения не допускаются.

+ Строковые константы в предикатах не поддерживают экранирование и чувствительны к регистру (в соответствии с collation типа).

+ При использовании оператора % для типов real и double precision генерируется ошибка, так как операция взятия остатка для них не определена.

+ Результат арифметических функций ограничен диапазоном типа numeric; при переполнении которого возникает ошибка.

+ Функции array_min и array_max возвращают Datum, который может указывать на элемент исходного массива; копирование не производится. Это следует учитывать при использовании результата после освобождения массива.
