# pg_array_agg: агрегатные функции для массивов в PostgreSQL

    Расширение pg_array_agg предоставляет набор агрегатных функций, которые принимают на вход массив (одномерный, двумерный или пустой) и возвращают скалярное значение. Функции позволяют вычислять произведение, сумму, среднее арифметическое, минимальный и максимальный элементы, а также подсчитывать количество элементов, удовлетворяющих условию, и проверять выполнение условий для всего массива или его части, проверять невыполнение условия для всего массива. Поддерживаются числовые и строковые типы данных, а также специальные значения (NaN, Infinity, -Infinity).

### Поддерживаемые типы данных

Расширение работает со следующими типами элементов массивов:

+ Числовые: `smallint, integer, bigint, decimal, numeric, real, double precision.`

+ Строковые: `character varying(n), varchar(n), character(n), char(n), text.`

Для арифметических функций (array_product, array_sum, array_avg) и функций экстремумов (array_min, array_max) допускаются только числовые типы. Для функций с предикатами и array_count — как числовые, так и строковые.

Специальные значения NaN, Infinity, -Infinity поддерживаются для числовых типов, которые их допускают (numeric, decimal, real, double precision). Правила сравнения и арифметики соответствуют встроенным правилам PostgreSQL.

### Особенности реализации

+ Итеративный обход массива. Для обработки больших массивов используется итератор PostgreSQL, что позволяет избежать полного развёртывания массива в памяти.

+ Предикатный движок. Разбор предиката выполняется в три этапа: лексический анализ, синтаксический анализ и приведение констант к типу элементов массива. Подготовленный предикат может многократно применяться к элементам без повторного разбора.

+ Универсальные вспомогательные функции. Сравнение, проверка на ноль, преобразование типов и арифметические операции вынесены в отдельные функции, что упрощает поддержку и расширение.

+ Расширяемость. Архитектура допускает добавление поддержки многомерных массивов и новых типов без существенной переработки кода.
