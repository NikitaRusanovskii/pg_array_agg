# Документация.
## Инструкция по установке расширения:

### Поддерживаемые версии Postgres: 15, 16, 17, 18, 19, 20(master)

### Установка в Contrib:
    1. Скопируйте содержимое папки pg_array_agg в postgres/contrib. postgres/ должна содержать исходники именно той версии, на кластер которой вы хотите установить расширение.
    2. Соберите расширение
        ``` bash
            make
        ```
    3. Запустите регрессионные и TAP-тесты расширения
        ``` bash
            make check
        ```
    4. После успешного прохождения тестов, установите расширение
        ``` bash
            make install
        ```

### Установка с использованием PGXS
    1. Убедитесь, что pg_config доступен в PATH. Утилита должна принадлежать именно той версии Postgres, на кластер которой вы собираетесь установить расширение.
    2. Соберите расширение
        ``` bash
            make USE_PGXS=1
        ```
    3. Установите расширение
        ``` bash
            make install USE_PGXS=1
        ```
    4. Запустите регрессионные и TAP-тесты расширения (У вас должен быть запущен кластер с подходящей версией Postgres)
        ``` bash
            make installcheck USE_PGXS=1
        ```

### Подключение расширения
    1. Запустите кластер, куда необходимо установить расширение
    2. Подключитесь к кластеру.
    3. Используйте команды создания (и удаления расширения, если необходимо):
        ``` psql
            CREATE EXTENSION IF NOT EXISTS pg_array_agg;
            
            -- Используйте функции расширения
            
            DROP EXTENSION IF EXISTS pg_array_agg;
        ```
