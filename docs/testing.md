### Тестирование
Расширение сопровождается набором регрессионных тестов и TAP-тестов, проверяющих корректность работы функций на различных данных, включая граничные случаи и ошибочные ситуации.

### Запуск тестов
`make check` - для установки в contrib
`make installcheck USE_PGXS` - для установки с PGXS

### Группы тестов
Тесты разбиты на несколько групп. Результаты тестирования:

| Группа тестов | Тип | Описание | Статус |
| :--- | :--- | :--- | :--- |
| `agg_additional.sql` | SQL | Стресс-тесты и граничные случаи: работа с большими массивами (до 65 млн элементов), переполнение `numeric`, различные нижние границы, тестирование синтаксиса предикатов, ошибок парсинга, пустых массивов и спец. значений. | ✅ PASS |
| `agg_allanynone.sql` | SQL | Тестирование функций проверки условий: `array_all`, `array_any`, `array_none`. | ✅ PASS |
| `agg_arith.sql` | SQL | Тестирование арифметических функций с накоплением: `array_product`, `array_sum`, `array_avg`. | ✅ PASS |
| `agg_count_if.sql` | SQL | Тестирование функции подсчёта элементов по заданному предикату: `array_count_if`. | ✅ PASS |
| `agg_count.sql` | SQL | Тестирование функции подсчёта точных вхождений элемента: `array_count`. | ✅ PASS |
| `agg_minmax.sql` | SQL | Тестирование функций поиска экстремумов в массиве: `array_min`, `array_max`. | ✅ PASS |
| `001_transactions.pl` | TAP | Проверка работы всех функций внутри транзакций (`BEGIN`, `COMMIT`, `ROLLBACK`) и корректности возвращаемых результатов до, во время и после отката. | ✅ PASS |
| `002_parallel.pl` | TAP | Тестирование параллельного выполнения: 32 форка одновременно вызывают функции для проверки потокобезопасности и стабильности результатов. | ✅ PASS |
| `003_error_query.pl` | TAP | Тестирование обработки ошибок: проверка выброса исключений при подаче 3-мерных массивов (`ndim=3`) и неверных типов элементов, а также проверка работоспособности сервера после ошибки. | ✅ PASS |
