# Более подробное описание функций. 

### `array_product`

**Общая сигнатура функции:** `array_product(anyarray) -> numeric`

**SQL-сигнатура:** `array_product(anyarray) RETURNS numeric`

**C-сигнатура:** `Datum array_product(PG_FUNCTION_ARGS)`

**Параметры входного массива:**
- Длина: произвольная.
- Число измерений: `0 <= ndim <= 2`.
- Типы элементов: `smallint`, `integer`, `bigint`, `decimal`, `numeric`, `real`, `double precision`.
- Функция `STRICT`; массив или элемент `NULL` приводит к `NULL`.

**Алгоритмическое решение и пояснение.**

Массив обходится итератором. Каждый элемент приводится к `numeric`, после чего накапливается произведение `res *= element` с использованием `numeric_mul`. Итератор позволяет обходить элементы без ручного вычисления нижней границы массива. Использование `numeric` снижает риск переполнения по сравнению с накоплением в целочисленном типе, но результат всё ещё ограничен диапазоном PostgreSQL `numeric`.

**Таблица поведения функции при различных параметрах**

| Входные данные / условие | Результат |
|---|---|
| Аргумент массива `NULL` | `NULL` |
| Ноль аргументов | `NULL` согласно описанному для `STRICT` поведению; фактическая SQL-вызовимость без аргумента определяется сигнатурой |
| Более одного аргумента | `ERROR` при обнаружении лишних аргументов реализацией; SQL-сигнатура сама по себе не допускает такой вызов |
| `{}`, `ndim = 0` или `ndim = 1`, ожидаемый тип | `1` — нейтральный элемент умножения |
| `{A1}` | `A1` после преобразования к `numeric` |
| `{A1, A2, …, An}` | `A1 * A2 * … * An` |
| Массив содержит хотя бы один `NULL` | `NULL` |
| `ndim > 2`, включая пустой массив | `ERROR` |
| Тип элемента не входит в список ожидаемых | `ERROR` |
| `{NaN}` | `NaN` |
| `{Infinity}` / `{-Infinity}` | `Infinity` / `-Infinity` |
| `NaN` присутствует среди элементов | `NaN` |
| `Infinity` или `-Infinity` умножается на конечное ненулевое значение | Бесконечность с соответствующим знаком |
| `Infinity` или `-Infinity` умножается на `0` | `NaN` |
| `{ -Infinity, Infinity }` | `-Infinity` согласно приведённому примеру исходной спецификации |
| Переполнение `numeric` | `ERROR` |

### `array_sum`

**SQL-сигнатура:** `array_sum(anyarray) RETURNS numeric`

**C-сигнатура:** `Datum array_sum(PG_FUNCTION_ARGS)`

**Параметры входного массива:**
- Длина: произвольная.
- Число измерений: `0 <= ndim <= 2`.
- Типы элементов: `smallint`, `integer`, `bigint`, `decimal`, `numeric`, `real`, `double precision`.
- Функция `STRICT`; массив или элемент `NULL` приводит к `NULL`.

**Алгоритмическое решение и пояснение.**

Массив обходится итератором. Каждый элемент приводится к `numeric`; накопление суммы выполняется как `res += element` с помощью `numeric_add`. Преобразование к `numeric` снижает риск переполнения при суммировании, но не отменяет ограничения самого `numeric`.

**Таблица поведения функции при различных параметрах**

| Входные данные / условие | Результат |
|---|---|
| Аргумент массива `NULL` | `NULL` |
| `{}`, `ndim = 0` или `ndim = 1`, ожидаемый тип | `0` — нейтральный элемент сложения |
| `{A1}` | `A1` после преобразования к `numeric` |
| `{A1, A2, …, An}` | `A1 + A2 + … + An` |
| Массив содержит хотя бы один `NULL` | `NULL` |
| `ndim > 2`, включая пустой массив | `ERROR` |
| Тип элемента не входит в список ожидаемых | `ERROR` |
| `{NaN}` или массив содержит `NaN` | `NaN` |
| `{Infinity}` / `{-Infinity}` | `Infinity` / `-Infinity` |
| `Infinity` вместе с конечными значениями, не содержащими противоположную бесконечность или `NaN` | `Infinity` |
| `-Infinity` вместе с конечными значениями, не содержащими противоположную бесконечность или `NaN` | `-Infinity` |
| В массиве присутствуют `Infinity` и `-Infinity` | `NaN` |

### `array_avg`

**Общая сигнатура функции:** `array_avg(anyarray) -> numeric`

**SQL-сигнатура:** `array_avg(anyarray) RETURNS numeric`

**C-сигнатура:** `Datum array_avg(PG_FUNCTION_ARGS)`

**Параметры входного массива:**
- Длина: произвольная.
- Число измерений: `0 <= ndim <= 2`.
- Типы элементов: `smallint`, `integer`, `bigint`, `decimal`, `numeric`, `real`, `double precision`.
- Функция `STRICT`; массив или элемент `NULL` приводит к `NULL`.

**Алгоритмическое решение и пояснение.**

Итератором обходятся все элементы массива. Каждый элемент приводится к `numeric`, сумма накапливается через `numeric_add`, затем сумма делится на количество элементов через `numeric_div`: `avg = sum / n`. Для пустого массива возвращается `NULL`, поскольку среднего арифметического без элементов нет.

**Таблица поведения функции при различных параметрах**

| Входные данные / условие | Результат |
|---|---|
| Аргумент массива `NULL` | `NULL` |
| `{}`, `ndim = 0` или `ndim = 1`, ожидаемый тип | `NULL` |
| `{A1}` | `A1` после преобразования к `numeric` |
| `{A1, A2, …, An}` | `(A1 + A2 + … + An) / n` |
| Массив содержит хотя бы один `NULL` | `NULL` |
| `ndim > 2`, включая пустой массив | `ERROR` |
| Тип элемента не входит в список ожидаемых | `ERROR` |
| `{NaN}` или массив содержит `NaN` | `NaN` |
| `{Infinity}` / `{-Infinity}` | `Infinity` / `-Infinity` |
| В массиве присутствуют `Infinity` и `-Infinity` | `NaN` |
| Переполнение `numeric` или ошибка арифметической операции | `ERROR` |

### `array_min`

**Общая сигнатура функции:** `array_min(anyarray) -> anyelement`

**SQL-сигнатура:** `array_min(anyarray) RETURNS anyelement`

**C-сигнатура:** `Datum array_min(PG_FUNCTION_ARGS)`

**Параметры входного массива:**
- Длина: произвольная.
- Число измерений: `0 <= ndim <= 2`.
- Поддерживает типы: `smallint`, `integer`, `bigint`, `decimal`, `numeric`, `real`, `double precision`.
- Функция `STRICT`; массив или элемент `NULL` приводит к `NULL`.

**Возвращаемое значение:**
- Datum элемента массива. Он может быть представлен указателем на элемент массива! Это требует аккуратного обращения с полученным значением.

**Алгоритмическое решение и пояснение.**

Итератором обходятся элементы массива. Минимум инициализируется первым элементом, затем для каждого следующего элемента вычисляется `min_el = min(min_el, element)`. Для сравнения используется универсальная функция cmp_op, использующая встроенные средства PostgreSQL

**Таблица поведения функции при различных параметрах**

| Входные данные / условие | Результат |
|---|---|
| Аргумент массива `NULL` | `NULL` |
| `{}`, `ndim = 0` или `ndim = 1, ожидаемый тип` | `NULL` |
| `{A1}` | `A1` |
| `{A1, A2, …, An}` | `min(A1, A2, …, An)` |
| Массив содержит хотя бы один `NULL` | `NULL` |
| `ndim > 2`, включая пустой массив | `ERROR` |
| Неожиданный тип | `ERROR` |
| `{-Infinity, NaN}` | `-Infinity` |
| `{Infinity, -Infinity}` | `-Infinity` |
| `{NaN, Infinity}` | `Infinity` |
| Сравнение невозможно для типа элемента | `ERROR` |

### `array_count`

**Общая сигнатура функции:** `array_count(anyarray, anyelement) -> integer`

**SQL-сигнатура:** `array_count(anyarray, anyelement) RETURNS integer`

**C-сигнатура:** `Datum array_count(PG_FUNCTION_ARGS)`

**Параметры входного массива:**
- Длина: произвольная.
- Число измерений: `0 <= ndim <= 2`.
- Типы элементов: числовые и строковые типы, перечисленные в общих правилах.
- Элемент для поиска должен иметь тип, совпадающий с типом элемента массива.
- `NULL` в массиве пропускается; функция `STRICT`.

**Алгоритмическое решение и пояснение.**

Счётчик инициализируется нулём. Итератором обходятся элементы; элементы `NULL` пропускаются, остальные сравниваются с искомым значением средствами PostgreSQL. При совпадении счётчик увеличивается. Результат имеет тип `integer`.

**Таблица поведения функции при различных параметрах**

| Массив | Искомый элемент | Результат |
|---|---|---|
| `NULL` | любое значение | `NULL` |
| Любой массив | `NULL` | `NULL` |
| `{}` с `ndim = 0` или `ndim = 1`, ожидаемый тип | ненулевое значение | `0` |
| `{NULL}` или массив только из `NULL` | ненулевое значение | `0` |
| `{A1, A2, …, An}` | `A1` | Число вхождений `A1` |
| `{A1, A2, A1, A3}` | `A1` | `2` |
| `{A1, A2}` | `A3`, отсутствующий в массиве | `0` |
| `{-0.0}` | `0.0` | `1` |
| `{Infinity}`, `{-Infinity}` или `{NaN}` | соответствующее значение | `1` |
| `ndim > 2` | любое значение | `ERROR` |
| Неожиданный тип массива или аргумента | любое значение | `ERROR` |
| Тип массива и тип искомого элемента несовместимы | любое значение | `ERROR` |
| Сравнение элементов вызывает ошибку | любое значение | `ERROR` |
| Количество совпадений выходит за диапазон `integer` | любое значение | `ERROR`, т.к. переполнение |

### `array_count_if`

**Общая сигнатура функции:** `array_count_if(anyarray, text) -> integer`

**SQL-сигнатура:** `array_count_if(anyarray, text) RETURNS integer`

**C-сигнатура:** `Datum array_count_if(PG_FUNCTION_ARGS)`

**Параметры входного массива:**
- Длина: произвольная.
- Число измерений: `0 <= ndim <= 2`.
- Типы элементов:
Числовые типы: `smallint`, `integer`, `bigint`, `decimal`, `numeric`, `real`, `double precision`.
Строковые типы: `character varying(n)`, `varchar(n)`, `character(n)`, `char(n)`, `text`.
- Предикат задаётся строкой типа `text`.
- Элементы `NULL` пропускаются; функция`STRICT`.

**Алгоритмическое решение и пояснение.**

Предикат обрабатывается собственным предикатным движком в несколько этапов: лексический анализ, синтаксический анализ и приведение констант к типу элементов массива. После подготовки предикат многократно вычисляется для элементов массива без повторного разбора исходной строки. Для каждого ненулевого элемента массива значение элемента подставляется вместо `x`; если условие истинно, счётчик увеличивается. Обход выполняется итератором. Строковые константы допускают только равенство и неравенство. Для константы, заданной как строка, предусмотрено принудительное приведение к строковому типу (исключением являются NAN, Infinity, -Infinity. Они приводятся к типу элемента массива).

**Таблица поведения функции при различных параметрах**

| Массив | Предикат / условие | Результат |
|---|---|---|
| `NULL` | любой предикат | `NULL` |
| Любой массив | `NULL` | `NULL` |
| `{}` с `ndim = 0` или `ndim = 1`, ожидаемый тип | пустой предикат| `0` |
| непустой массив, ожидаемый тип | пустой предикат | `0` |
| `{}` с `ndim = 0` или `ndim = 1`, ожидаемый тип | корректный предикат | `0` |
| `{NULL}` или массив только из `NULL` | корректный предикат | `0` |
| `{A1, A2, …, An}` | `x == A1` | Число элементов, равных `A1` |
| `{A1, A2, …, An}`, где `Ai < Ai+1` | `x > A1` | `n - 1` |
| `{A1, A2}` | `x == A3`, где `A3` отсутствует | `0` |
| `{Infinity}`, `{-Infinity}`, `{NaN}` | сравнение с соответствующей константой | `1`  |
| `{-0.0}` | `x == 0.0` | `1` |
| `ndim > 2` | любой предикат, кроме NULL | `ERROR` |
| Неожиданный тип элемента | любой предикат, кроме NULL | `ERROR` |
| Лексически некорректный предикат | любой предикат, кроме NULL | `ERROR` |
| Синтаксически некорректный предикат | любой предикат, кроме NULL | `ERROR` |
| Константу нельзя привести к типу элементов массива | любой предикат, кроме NULL | `ERROR` |
| Оператор не поддерживается для данного типа, включая упорядочивающий оператор для строк | любой предикат, кроме NULL | `ERROR` |
| Деление по модулю на ноль или иная ошибка операции | любой предикат, кроме NULL | `ERROR` |
| Счётчик выходит за диапазон `integer` | любой предикат, кроме NULL | `ERROR` |
| `{MIN_INT}` | `x % -1 = 0` | `1` поскольку MIN_INT % -1 приводит к переполнению, для него была определена константа 0 в качестве результата |
| `{...}` | `x % 0 = ...` | `ERROR` |
| `{}` | `''` | `0` |

| Массив | Предикат / условие | Результат |
|---|---|---|
| `NULL` | любой предикат | `NULL` |
| Любой массив | `NULL` | `NULL` |
| `{}` с `ndim = 0` или `ndim = 1`, ожидаемый тип | пустой предикат| `false` |
| непустой массив, ожидаемый тип | пустой предикат | `false` |
| `{}` с `ndim = 0` или `ndim = 1`, ожидаемый тип | корректный предикат | `false` |
| `{NULL}` или массив только из `NULL` | корректный предикат | `false` |
| `{A1, A2, …, An}` | `x == A1` | `true`, если хотя бы один элемент равен `A1` |
| `{A1, A2, …, An}`, где `Ai < Ai+1` | `x >= A1` | `true`  |
| `{A1, A2}` | `x == A3`, где `A3` отсутствует | `false` |
| `{Infinity}`, `{-Infinity}`, `{NaN}` | сравнение с соответствующей константой | `true`  |

| `{...}` | `x % 0 = ...` | `ERROR` |
| `{}` | `''` | `false` |

### `array_none`

**Общая сигнатура функции:** `array_none(anyarray, text) -> boolean`

**SQL-сигнатура:** `array_none(anyarray, text) RETURNS boolean`

**C-сигнатура:** `Datum array_none(PG_FUNCTION_ARGS)`

**Параметры входного массива:**
- Длина: произвольная.
- Число измерений: `0 <= ndim <= 2`.
- Типы элементов:
Числовые типы: `smallint`, `integer`, `bigint`, `decimal`, `numeric`, `real`, `double precision`.
Строковые типы: `character varying(n)`, `varchar(n)`, `character(n)`, `char(n)`, `text`.

## Алгоритмическая сложность функций:
* Обозначим за O(func) сложность некоторой функции func
* n - кол-во элементов в массива
* m - длина строки предиката
* res - результирующий элемент

** Алгоритмическая сложность вычислялась, абстрагировавшись от сложности служебных функций PostgreSQL. Это стоит брать во внимание, поскольку array_product для [1, ..., N] может оказаться неочевидно длительной операцией, поскольку происходит много промежуточных вычислений c Numeric, которые являются очень затратными при разрастании разрядности числа **

| Функция | Время | Память |
|---|---|---|
| `array_product` | `O(n * O(mul))` | `O(1) + O(res)` |
| `array_sum` | `O(n * O(add))` | `O(1) + O(res)` |
| `array_avg` | `O(n * O(add) + O(div))` | `O(1) + O(res)` |
| `array_min` | `O(n * O(cmp))` | `O(1)` |
| `array_max` | `O(n * O(cmp))` | `O(1)` |
| `array_count` | `O(n * O(cmp))` | `O(1)` |
| `array_count_if` | `O(m + n * O(exec_predicate))` | `O(m)` |
| `array_all` | `O(m + n * O(exec_predicate))` | `O(m)` |
| `array_any` | `O(m + n * O(exec_predicate))` | `O(m)` |
| `array_none` | `O(m + n * O(exec_predicate))` | `O(m)` |


## Описание вспомогательных функций 

### `bool type_is_expected(Oid type_oid, const Oid* expected_types, uint32 len)`
* Возвращает `true`, если `type_oid` содержится в `expected_types`.

### `Datum string_to_datum(char* str, int len, Oid target_oid)`
* Преобразует строку `str` длины `len` в `Datum` заданного типа `target_oid`.

### `Token construct_token(TokenType type, const char* token, int32 lenght)`
* Создаёт и возвращает токен с указанными типом, значением и длиной.

### `int32 lexical_analyze(char* predicate_string, int32 len, Token* result, int32 token_len)`
* Разбивает строку предиката на токены и возвращает их количество, включая завершающий `T_END`.

### `int32 syntaxical_analize(Token* parsed_tokens, int32 len, ParsedPredicate* predicate)`
* Проверяет соответствие токенов грамматике предиката и заполняет структуру `predicate`.

### `void cast_predicate(ParsedPredicate* parsed, Predicate* result, Oid target_oid)`
* Проверяет допустимость оператора для типа `target_oid` и преобразует константы в `Datum`.

### `int32 cmp_op(Oid target_oid, Datum first, Datum second, Oid collid)`
* Сравнивает два значения заданного типа с учётом collation через кэшированный `cmp_proc`.

### `bool datum_is_zero(Datum value, Oid type_oid, Oid collid)`
* Проверяет, равен ли `value` нулю для заданного типа.

### `Datum mod_op(Oid target_oid, Datum first, Datum second, Oid collid)`
* Вычисляет остаток от деления для поддерживаемых целочисленных типов и `NUMERICOID`; при нулевом делителе вызывает ошибку.

### `Numeric datum_to_numeric(Datum element, Oid type_oid)`
* Преобразует `Datum` в `Numeric` для арифметических операций.

### `int32 prepare_predicate(Datum predicate_text, Oid target_oid, Predicate* predicate, Oid collid)`
* Выполняет лексический анализ, синтаксический разбор и преобразование констант предиката; возвращает длину строки или `0` для пустого предиката.

### `bool execute_predicate(Predicate* predicate, Datum element, Oid target_oid, Oid collid)`
* Вычисляет подготовленный предикат для одного элемента массива.

### `void free_predicate(Predicate* predicate)`
* Освобождает память, выделенную под константы предиката.
